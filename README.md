## About Me

I am an IT Specialist and cybersecurity enthusiast with a strong interest in security governance, infrastructure protection, secure application practices, and digital public service improvement.

I currently contribute in a government treasury systems environment, where I focus on practical technology implementation, information security, IT governance, and operational reliability. I enjoy building lightweight tools that support security awareness, incident response, internal governance, civic-tech initiatives, and community-based digital services.

- **Current focus:** cybersecurity governance, penetration testing workflow, secure IT operations, and cloud security practices.
- **Professional interest:** security tooling, ITSM, infrastructure security, compliance, DevSecOps, and public sector digital transformation.
- **Academic background:** information security, computer science, and governance-oriented technology implementation.
- **Open to collaborate on:** security tools, governance frameworks, community platforms, civic-tech projects, and meaningful digital services.
